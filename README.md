# MoodTune

MoodTune is an AI-assisted music therapy and personalised music
recommendation application. It analyses music features and recommends
music based on the user's emotional state and regulation goals.

## Project Overview

The project aims to provide a personalised music therapy experience
through emotion-aware music recommendation and audio feature analysis.

## Key Features

- Personalised music recommendation
- User emotional state assessment
- Music feature extraction
- AI-assisted music classification
- Spotify music service integration
- Android application demonstration

## Technology Stack

- Python
- Flask
- Librosa
- Machine Learning
- Flutter
- Spotify API
